# 06 - TechTales Finance App

## 💰 Summary
A lightweight financial analytics tool built with Streamlit and Plotly that reads bank transaction statements and visualizes expense breakdowns by category. Aimed at simplifying personal finance insights.

---

## 🚀 Features

- 📊 **Category-Wise Expense Breakdown**  
  Pie chart visualization of transactions grouped by categories.

- 📝 **Statement Parsing**  
  Parses CSV-based bank statements and structures them for display.

- 🔄 **Amount or Percentage Toggle** (in progress)  
  Switch between percentage and absolute amount in the chart view.

- 🧠 **Fuzzy Matching for Categorization** (planned)  
  Auto-categorization of transactions using fuzzy string matching.

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Plotly
- Pandas
- FuzzyWuzzy (for future improvements)
- dotenv

---

## 🌟 Key Learnings

- 📊 Gained experience using Plotly for clean and interactive graphs.
- 💬 Created intuitive UI with Streamlit for non-technical users.
- 🧠 Explored fuzzy logic and how it enhances user experience.
- 📄 Improved file parsing and exception handling.

---

## ✅ Pros & Cons

**Pros**:
- Easy-to-use personal finance visualizer.
- Great potential for feature expansion.

**Cons**:
- Current parser works on specific CSV formats.
- Lacks secure data storage (intended for local/personal use).
