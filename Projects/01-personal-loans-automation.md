# 01 - Personal Loans Automation

## 📝 Summary
This was my first QA automation project, focused on personal loan workflow testing using Selenium.

## 🔧 Tech Stack
- Python
- OpenPyXL
- Selenium WebDriver
- Excel-based test data

## 🧪 Key Features
- End-to-end UI flow validation
- Loan application form automation
- Basic reporting and assertions
- Capture screenshots for validation

## 💡 Learnings
- Locators and waits in Selenium
- Script structuring for modularity
- Importance of test data design
