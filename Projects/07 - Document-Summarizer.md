🧠 Summary
A practical and user-friendly app that leverages Azure OpenAI to automatically summarize the contents of uploaded documents. With support for .txt, .pdf, and .docx formats, this Streamlit-based tool helps users quickly extract key information from lengthy files, making document review and knowledge sharing more efficient.

🧪 Use Case
This project is designed to:

Simplify the process of understanding large or complex documents.
Enable quick summarization for project reports, meeting notes, research papers, and more.
Provide a foundation for integrating advanced AI-powered document analysis into business workflows.
🚀 Features
Multi-format Upload: Accepts text, PDF, and Word documents.
AI Summarization: Uses Azure OpenAI to generate concise summaries.
Web Interface: Easy-to-use Streamlit UI for uploading and viewing results.
Secure Setup: Credentials managed via .env for safe API access.
