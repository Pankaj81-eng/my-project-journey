# Retrieval Systems

AI tools that retrieve, generate, and structure information from external sources. These projects explore RAG pipelines, LLM-driven generation, and document-based retrieval.

| Project | Description |
|---|---|
| [AI Test Case Generator](AI-Test-Case-Generator/) | LLM-driven test case generation from natural language prompts with RAG enrichment |
| [AI Test Data Generator](AI-Test-Data-Generator/) | Synthetic test data generation using OpenAI with schema-driven field definitions |
| [Azure AI Search - Document Q&A](Azure-AI-Search-RAG/) | Document upload, indexing and full-text retrieval on Azure Blob Storage + Azure AI Search |
